# LinguIA

Plataforma que busca democratizar el acceso al aprendizaje de idiomas.

LinguIA tiene como objetivo ofrecer un tutor de IA personalizado con diagnóstico inicial, planificación, práctica, evaluación y seguimiento persistente. Comenzará con inglés y una arquitectura extensible a otros idiomas.

**Estado:** inicio del proyecto; documentación de base. Este repositorio todavía no contiene una aplicación, un diagnóstico validado ni un tutor implementado.

## Recorrido educativo

Evaluación diagnóstica obligatoria → informe con evidencias → roadmap personalizado → clases completas → evaluación, repaso y adaptación.

El dashboard reflejará los registros reales del aprendizaje. Los niveles serán estimaciones fundamentadas, sin presentarlos como certificaciones oficiales.

## Principios

- Un único repositorio principal para código, pruebas y documentación.
- Arquitectura modular y programación orientada a objetos donde corresponda.
- Lenguajes seleccionados según la necesidad de cada componente.
- Integración progresiva de IA, con pruebas desde etapas tempranas.
- Presupuesto inicial de $0 y prioridad al acceso gratuito.
- Memoria pedagógica controlada por el estudiante y evaluaciones trazables.

## Desarrollo y apertura

El stack, el alojamiento y la licencia están pendientes de selección. La aspiración es desarrollar un proyecto open source; la visibilidad pública por sí sola no concede una licencia de código abierto.

No incorporar credenciales, conversaciones privadas, progreso real ni grabaciones personales al repositorio. Utilizar ejemplos sintéticos.
